# neuro-publishing-agents-perspective

A perspective on how AI agents participate in neuroscience publishing: authorship, disclosure, accountability, and machine-readable scientific communication.

## Overview

Scientific papers are written for humans, but they are increasingly consumed and synthesized by machines. This project collects notes, outlines, and agent definitions for a perspective on what that shift means for neuroscience publishing—especially around naming, crediting, and verifying AI-assisted work.

## Structure

```
perspective/   Manuscript outline and draft sections
agents/        Illustrative agent roles and naming conventions
docs/          Supporting notes on attribution and disclosure
```
